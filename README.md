# Quantium Data Analytics – Trial Store Performance Evaluation

## 📌 Project Overview
This project was completed as part of the **Quantium Data Analytics Virtual Experience Program (Forage)**.  
The objective was to analyse customer purchasing behaviour and evaluate the performance of trial stores using a **trial vs control store methodology**, and to present actionable business recommendations.

---

## 🎯 Objectives
- Analyse customer segments and purchasing behaviour
- Evaluate the effectiveness of a retail trial using matched control stores
- Identify statistically significant sales uplift
- Translate analytical findings into clear, client-ready recommendations

---

## 🗂️ Datasets
The analysis uses transaction-level retail data provided as part of the Quantium virtual internship, including:
- Customer purchasing data
- Store-level transaction data
- Trial and control store information

---

## 🛠️ Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

---

## 📊 Key Analysis Performed
- Data cleaning and preprocessing
- Customer segmentation analysis
- Trial vs control store matching
- Time-series sales comparison
- Statistical significance testing
- Data visualisation and interpretation

---

## 📈 Key Insights
- Family households and mainstream customers contribute the highest share of chip sales
- Trial Stores 86 and 88 showed statistically significant uplift compared to control stores
- Trial Store 77 did not demonstrate consistent positive uplift
- Trial effectiveness varies by store characteristics

---

## ✅ Recommendations
- Roll out the trial strategy selectively to stores similar to 86 and 88
- Avoid scaling the trial to stores similar to 77 without further investigation
- Use customer segmentation to guide future promotional strategies
